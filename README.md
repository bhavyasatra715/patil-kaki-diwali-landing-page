# Patil Kaki Diwali Faral — Prototype

A responsive, static landing-page prototype based on the Diwali concept shared in the design conversation. It is built with plain HTML, CSS, and JavaScript so it can be hosted on GitHub Pages without a build step.

## Preview

After GitHub Pages is enabled, the preview is available at:

`https://bhavyasatra715.github.io/patil-kaki-diwali-landing-page/`

## Interactions

- Category cards link to the live Patil Kaki snack and ladoo collections.
- Search filters products by name.
- Add buttons and the two faral pairings update a demo cart.
- Product links open the current Patil Kaki catalog pages.
- The cart is for preview only; it does not connect to Shopify or take orders.

## Catalog values

Individual prices and pack sizes in this prototype were checked on [patilkaki.com](https://patilkaki.com/) on 12 October 2026. They can change. The combo totals are sums of the displayed individual prices; they are not published bundle prices or discounts.

The locally bundled food images, including the Diwali hero scene, are illustrative concept art, not official Patil Kaki product photography. Replace/confirm all photography, copy, prices, stock status, fulfilment details, and gifting links with the business before using this as a live storefront.

## Run locally

Open `index.html` in a browser. No dependencies or build step are required.

This is an independent design prototype and is not an official Patil Kaki website.
